## ☁️ Overview

This repository contains the source code for my personal professional portfolio, designed and developed using Quarto, HTML, and CSS.

The website showcases my academic background, professional experience, technical skills, and projects in data science, applied mathematics, statistics, and actuarial science.

The design combines a professional presentation with a personalized pastel-blue aesthetic, animated clouds, and responsive layouts.

## 📂 Website Structure

| File or Directory | Description |
|---|---|
| `_quarto.yml` | Website configuration and navigation |
| `index.qmd` | Homepage and featured projects |
| `about.qmd` | Academic background, experience, and personal interests |
| `projects.qmd` | Data science and actuarial project portfolio |
| `resume.qmd` | Embedded and downloadable résumé |
| `styles.css` | Custom styling, animations, and responsive layouts |
| `images/` | Website images and project visuals |
| `resume_files/` | Résumé document |

## 🛠️ Running the Website Locally

To preview the website locally, install Quarto and clone this repository.

```bash
git clone https://github.com/maxinehb/personal-website.git
cd personal-website
quarto preview
```

To render the complete website:

```bash
quarto render
```
